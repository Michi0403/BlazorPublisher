# PublisherStudio 2.3.3

- Keeps the Kawaii documentation theme selector inside the navbar and viewport on generated and static snapshot pages.
- Publishes `api/index.html` and the complete `api` tree explicitly into every application documentation root.
- Fails documentation publication if the API entry point is absent before or after either publication copy.
- Strengthens the GitHub Pages workflow gate with a case-sensitive `api/index.html` check and a non-empty API HTML count.
- Preserves the working PDF/HTML viewer, Pages snapshot flow, frontend SHA refresh workflow, and existing Kawaii design.
