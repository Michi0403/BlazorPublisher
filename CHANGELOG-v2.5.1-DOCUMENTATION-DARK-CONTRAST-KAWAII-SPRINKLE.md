# PublisherStudio 2.5.1 — Documentation dark contrast + kawaii sprinkle

- Repairs dark-mode contrast for DocFX cards, details, tabs, API member surfaces, neko notes, callouts, headings and footer text.
- Keeps the pastel gradient identity while giving gradient labels a subtle contrast shadow in dark mode.
- Adds a restrained animated star-sprinkle layer behind documentation content.
- Adds tiny delegated hover sprinkles (stars + one paw) around interactive documentation controls without replacing existing control pseudo-elements.
- Honors `prefers-reduced-motion`; hover particles are disabled and star motion is reduced to a static layer.
- Synchronizes template, maintained style/script resources, embedded help-doc assets and the tracked Pages snapshot cache keys.
- Extends the documentation contract audit with the new contrast/motion markers.
- PublisherStudio Web and InstallerConsole bumped to 2.5.1.
