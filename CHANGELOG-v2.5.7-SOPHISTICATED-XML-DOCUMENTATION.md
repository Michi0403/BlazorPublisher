# PublisherStudio 2.5.7 changelog

## Comprehensive XML documentation restoration and enrichment

- Re-reviewed the maintained PublisherStudio C# source from the buildable 2.5.6 baseline and enriched documentation across editor/runtime services, controllers, publication models, Panel Studio, Organic/1-Wire integration, media/streaming/OpenSCAD infrastructure, installer code, helpers, and private implementation state.
- XML documentation now covers **5,337 direct maintained C# type/member declarations**, regardless of public/private/internal accessibility: 338 classes, 66 interfaces, 77 records, 10 structs, 114 enums, 9 delegates, 43 constructors, 2,074 methods, 2,100 properties, 481 fields, and 25 events.
- Replaced prior name-only/generated summaries with contextual documentation based on each member's containing service/controller/model, domain responsibility, parameters, result type, and current source structure.
- Rich authored comments are preserved instead of being replaced by generic generated wording.
- Added missing `<param>`, `<typeparam>`, `<returns>`, and property `<value>` tags where applicable, including private implementation members and primary-constructor contracts.
- Generated Designer/g.cs and `<auto-generated>` sources remain excluded from source-authored documentation enforcement.

## Documentation tooling and architecture guard

- Reworked the existing XML documentation scripts around deterministic `build/xml_documentation.py` parsing and validation.
- The enhancer only edits comments attached to direct C# type/member declarations; raw-string templates, method bodies, argument expressions, and generic `where` clauses are not documentation insertion sites.
- The assertion verifies contextual summaries and contract tags for private members as well as public API members.
- A second enhancer pass reports zero changes, making the maintained documentation rule deterministic and idempotent.
- Corrected the architecture audit's beginning-of-line whitespace matching so blanked XML-comment lines cannot be consumed as part of the following static declaration; the underlying static-state policy is unchanged.

## Source integrity

- A token-equivalence audit confirms that all 180 maintained C# files remain code-equivalent to the 2.5.6 baseline after comments are removed; no PublisherStudio runtime/editor behavior was changed by the documentation pass.
- Existing Panel Studio persistence, Organic/1-Wire Ping/Pong and live capability synchronization, AI Assist, export, media, and viewport behavior remains intact.
- Generated DocFX output was deliberately **not regenerated** in this source-only environment. The next owner build/DocFX run can regenerate the product documentation from the enriched authoritative source comments.

## Version

- PublisherStudio Web/installer: **2.5.7**.
- The consumed LocalGPT 1-Wire protocol remains **2.1.1**; no protocol schema changed.
