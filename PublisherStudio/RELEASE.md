# PublisherStudio v1.0.89 source candidate

See `CHANGELOG-v1.0.89.md`, `CHANGELOG-v1.0.88.md` and `docs/architecture/task-ledger.md`.

v1.0.89 adds the user-gated LocalGPT organic-plugin bridge while preserving the normal application and installer bootstrap. UDP discovery and the TCP service are optional, capability-based and separate from the PublisherStudio web port. OpenSCAD work reuses the canonical document/node renderer architecture; spreadsheet help uses sequential hand-eye work packages.

Application and installer version is `1.0.89`. Publication format remains `1.55`. Repository source-contract, JavaScript, JSON and XML validation is recorded by the test suite. Native .NET 10, Razor and licensed DevExpress compilation plus browser/device permission acceptance remain mandatory on the developer workstation before publishing binaries.
