# PublisherStudio v1.0.83 release

See `CHANGELOG-v1.0.83.md`, `SOURCE-CHANGES-v1.0.83.txt`, `TEST-RESULTS-v1.0.83.txt`, and `docs/architecture/video-selection-3d-html-interchange-v1.0.83.md`.

v1.0.83 turns committed Video Studio ranges into reusable effect layers, fixes persistent polygon-point ownership and exact deletion, adds animated 3D blob layers with OpenSCAD interchange, and makes those objects directly reusable in Mainframe, Panel Studio and HTML export.

Application and installer version is `1.0.83`. Publication format remains `1.55`; package dependency names and versions are unchanged.
