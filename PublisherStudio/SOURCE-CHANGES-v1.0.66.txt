Reintegrate the compiler repairs from Michael's uncommitted working tree into the clean

Working-tree comparison
-----------------------
The uploaded PublisherStudio(15).zip contained Git metadata, Visual Studio state, IDE
personalization and restored node_modules. Its PublisherStudio source directory was

No IDE metadata, Git metadata, build output or dependency directory from the uploaded
working tree was copied into the release source.

Why the Encoding fix is required
--------------------------------
PublisherStudio already contains the namespace PublisherStudio.Services.Streaming.Encoding.
Inside sibling namespaces such as PublisherStudio.Services.Streaming.Chat and .Lan, C#
name lookup can resolve the simple identifier Encoding to that namespace instead of the
System.Text.Encoding type imported through using System.Text.

The release keeps the existing namespace for compatibility and explicitly uses
`global::System.Text.Encoding` at affected call sites.

----------------------------

Added:
- docs/decisions/ADR-008-compiler-visible-namespace-and-composition-safety.md

The rules now require:
- Namespace leaves are treated as compiler-visible architecture.
- New namespace leaves avoid visible framework/project type-name collisions.
- Existing collisions use global:: qualification or an explicit alias.
- Moving a Service, Hub, HostedService, Controller or shared contract updates composition-
  root imports/qualifications in the same change.
- A real dotnet build is required when the SDK and licensed DevExpress feed are available.
  Static checks must not be described as compilation.

Executable prevention
---------------------
Added tests/csharpCompilationSafety.test.mjs and package script test:compilation-safety.
The aggregate npm test now runs 16 suites.

The new suite:
- Resolves project types used by DI registrations in Program.cs and
  *ServiceCollectionExtensions.cs and checks namespace visibility.
- Detects common framework identifiers used unqualified when a sibling project namespace
  shadows the same simple name.
- Locks the HostedServices.Streaming import and System.Text.Encoding qualification repairs.
