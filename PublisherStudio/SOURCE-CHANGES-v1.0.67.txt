PublisherStudio v1.0.67 source changes
======================================

Base
----
- PublisherStudio v1.0.66 compiler-safe reintegration source.

Compiler correction
-------------------
- src/PublisherStudio.Web/Services/Streaming/Lan/RtspLanServer.cs
  - Replaced direct global::System.Text.Encoding expressions with the explicit
    TextEncoding file alias.
  - Moved SDP ASCII byte-count calculation into a local contentLength value.
  - Kept the Content-Length interpolation to a simple integer expression, avoiding
    C# interpolation-format parsing of the :: token.
- src/PublisherStudio.Web/Services/Streaming/Chat/PlatformChatService.cs
  - Replaced repeated global::System.Text.Encoding expressions with the same
    explicit TextEncoding alias for consistent collision handling.

Prevention and repository guidance
----------------------------------
- AGENTS.md
  - Documents why {global::...} is invalid when global:: begins an interpolation hole.
  - Prefers deliberate file-level aliases for repeated or interpolated references.
- docs/decisions/ADR-008-compiler-visible-namespace-and-composition-safety.md
  - Corrected and strengthened the namespace-collision decision for v1.0.67.
- docs/ARCHITECTURE.md and docs/architecture/system-overview.md
  - Record the alias-first interpolation-safe rule.
- VALIDATION.md
  - Adds the exact regression checks and reiterates that static checks do not replace
    a licensed dotnet build.
- tests/csharpCompilationSafety.test.mjs
  - Requires the TextEncoding aliases at both known Streaming collision sites.
  - Rejects unparenthesized {global::...} interpolation/expression holes.
  - Verifies RTSP calculates and formats Content-Length through the local value.

Release metadata
----------------

- Updated RELEASE.md and README.md.

- Updated version contracts in fontIntegration and streamingRuntime tests.
