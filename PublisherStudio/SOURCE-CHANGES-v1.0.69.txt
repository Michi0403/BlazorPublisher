PublisherStudio v1.0.69 source changes
======================================

Baseline
--------
PublisherStudio v1.0.68 media-gesture-editing source.

Video Studio spatial selection workflow
---------------------------------------
- Replaced the passive SVG over the native video element with a dedicated local
  interaction host that becomes pointer-active only in Frame region mode.
- The active overlay blocks the native player for the owned pointer sequence, so
  clicks/touches reach the region tool instead of the browser's video controls.
- Added a canvas-style crosshair, outside-region dimming, visible vertices and
  cutline, plus local Apply region, Undo point and Exit mode actions.
- The full source remains visible while a region is being edited; the committed
  clip path is restored after apply/cancel.
- Added browser-side source-frame alignment based on videoWidth/videoHeight and
  the rendered object-fit rectangle, including letterbox compensation.
- Added deterministic cleanup for overlay listeners and ResizeObserver.

Picture Studio selection workflow
---------------------------------
- Added a canvas-local, pointer-transparent gesture guide and crosshair for
  rectangle, ellipse, freehand, magnetic and polygon selection modes.
- Added a selection veil that keeps the selected area visible while shading the
  outside, with explicit boundary and vertex handles.
- The guide and veil are transient projections and are not added to Picture
  Studio layers or PublisherStudio page/Z-order state.

Stop Recording / short-duration range repair
--------------------------------------------
- Replaced direct trim Math.Clamp calls with NormalizeTrimRange, which first
  establishes a finite duration and a minimum span that cannot exceed it.
- Range-selector scale end and minimum range now derive from the actual finite
  media duration, including zero/sub-step recording-finalization states.
- Range-selector values are parsed defensively for boxed numeric values and the
  active UI culture (for example 0,01), preventing the callback from interrupting
  Stop Recording while the browser finalizes a short clip.
- Existing retained-recording download behavior remains unchanged.

Frontend and architecture rules
-------------------------------
- Expanded AGENTS.md with one-owner gesture rules, active/inactive overlay
  pointer ownership, local stacking contexts, source-frame coordinates,
  JavaScript/CSS high-frequency feedback, cleanup requirements and safe range
  normalization.
- Added ADR-010: Local Studio interaction overlays.
- Updated media-gesture architecture documentation and the repository overview.
- Explicitly protects Mainframe element identity, dimensions, rotation, group,
  connector, animation and Z-order orchestration from Studio overlays.
- Audio remains one-dimensional and uses only temporal range/section gestures.

Version and compatibility
-------------------------
- Application and installer version: 1.0.69.
- Publication format remains 1.49.
- Picture Studio format remains 1.4.
- No NuGet, npm, native binary or external process dependency was added.
