PublisherStudio v1.0.70 source changes
=====================================

Managed component-drop routing
------------------------------
- Domain/PublicationModels.cs
  Extended ExternalFileDropRequest with an optional target element identity, target kind and target-local coordinates.
- Components/Editor/PageSurface.razor
  Publishes element geometry to the browser and forwards compatible drop-target information to the Mainframe.
- wwwroot/js/publisherInterop.js
  Detects compatible picture/video/audio targets, computes target-local coordinates and provides target highlighting.
- Components/Pages/Editor.razor
  Routes picture-on-picture drops into Picture Studio layers and compatible media drops into the owning media sequence.

Picture Studio drop ownership
-----------------------------
- Components/Editor/PictureEditor.razor(.cs)
  Added Studio-local file inputs and positioned raster/layer import paths.
- Services/PictureDocumentService.cs
  Added managed raster-layer insertion support.
- Services/PictureEditorStateService.cs
  Added positioned imported-layer placement and state updates.
- wwwroot/js/pictureStudioInterop.js
  Added Picture Studio drag/drop binding and canvas-coordinate projection.

Video/Audio sequence insertion
------------------------------
- Services/MediaStudio/UseCases/MediaTimelineEditService.cs
  Added split-aware sequence insertion at a projected timeline timestamp.
- Components/Editor/MediaStudio.razor
  Added initial inserted-segment handling and Studio-local compatible file-drop behavior.
- wwwroot/js/mediaStudioInterop.js
  Added compatible media drop forwarding and drop-target feedback.

Video temporal selection and orchestration
------------------------------------------
- Components/Editor/MediaStudio.razor
  Added the video-frame timestamp/range overlay, selected-clip projection, editable selection values, cut/trim/copy commands, positioned insertion dialog and sequence selection marker. Removed native video editor controls.
- wwwroot/js/mediaStudioInterop.js
  Added browser-local timestamp/range gestures, live field/readout synchronization, selected-segment timeline projection and safe binding/disposal.
- wwwroot/css/site.css
  Added temporal handles, range shade, playhead, drop marker, insertion panel, selection values and sequence marker styling.

Video fit persistence
---------------------
- Domain/PublicationMediaModels.cs
  Added VideoFitMode to MediaEditorResult.
- Components/Editor/MediaStudio.razor
  Added Fit whole, Fill canvas and Stretch controls and recalculated overlay geometry after fit changes.
- Components/Pages/Editor.razor
  Applies the returned fit mode to the edited VideoElement.

Release metadata and tests
--------------------------
- Application, installer, runtime capability and web-assets versions updated to 1.0.70.
- Added mediaComponentDrop.test.mjs and videoTemporalOverlay.test.mjs.
- Updated package test orchestration, release notes, architecture guidance and validation notes.

Compatibility
-------------
- Publication format remains 1.49.
- Picture Studio format remains 1.4.
- No dependency versions changed.
