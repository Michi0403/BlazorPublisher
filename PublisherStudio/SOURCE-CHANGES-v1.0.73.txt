PublisherStudio v1.0.73 source changes
=====================================

Canonical project and persistence
---------------------------------
- Domain/PublicationMediaModels.cs
  Added typed timeline tracks/transitions, source references, project markers, VideoProjectDocument, explicit segment placement/rate/speed/gap/import metadata, and VideoProject on MediaEditorResult.
- Domain/PublicationModels.cs
  Added VideoElement.VideoProject, timeline-duration/speed-aware media length, and publication format 1.52.
- Domain/InterchangeModels.cs
  Added VideoProjectImportResult.
- Services/MediaStudio/UseCases/MediaTimelineEditService.cs
  Added deep canonical project cloning, active-track projection creation/replacement, gap/reference preservation, and timeline-duration/speed-aware segment operations.
- Services/PublicationFileService.cs
  Normalizes and migrates canonical projects/tracks, resolves the active track, restores the active legacy projection when needed, and writes format 1.52.
- Services/Publication/Import/OpenDocumentImportService.cs
  Creates imported publications at format 1.52.
- Components/Pages/Editor.razor
  Persists the cloned VideoProject returned by Video Studio.

Open project adapters
---------------------
- Services/VideoStudio/Import/VideoProjectImportService.cs
  Added bounded BCL-only import adapters for OpenTimelineIO, OTIOZ, MLT/Kdenlive/Shotcut, XGES, OpenShot OSP, and CMX 3600 EDL; canonical mapping; compatibility/loss reporting; missing-media references; safe JSON/XML/archive processing; and bundled-media matching.
- Program.cs and Components/_Imports.razor
  Registered and exposed the project importer through the existing composition root.

Video Studio workflow
---------------------
- Components/Editor/MediaStudio.razor
  Added ribbon/context project import and relink commands, hidden project inputs, project summary and compatibility report, editable video-track switching, offline/gap sequence states, canonical track commit/load, batch relinking, save/load persistence, and project-file drag/drop integration.
- wwwroot/js/mediaStudioInterop.js
  Recognizes supported project extensions and routes project drops to the open-project input while preserving ordinary media insert behavior.
- wwwroot/css/site.css
  Added imported-project summary/report and offline/gap sequence styling.

Documentation and tests
-----------------------
- docs/architecture/video-project-import-doctrine.md
  Added the fact-checked format/media doctrine, implemented compatibility matrix, roadmap, canonical mapping and safety rules.
- docs/architecture/interchange-formats.md and docs/ARCHITECTURE.md
  Documented v1.0.73 adapters, canonical ownership and the honest active-track projection limit.
- VALIDATION.md
  Added v1.0.73 adapter, relinking, security, persistence and package validation scenarios.
- tests/videoProjectImport.test.mjs
  Added contracts for the canonical model, adapter set/safety, Studio UI, project persistence, drag/drop, versions, doctrine and unchanged dependencies.
- Existing version/publication-format expectations were advanced to 1.0.73 / 1.52.
- Added CHANGELOG-v1.0.73.md, SOURCE-CHANGES-v1.0.73.txt and TEST-RESULTS-v1.0.73.txt; updated inner and outer RELEASE.md.

Compatibility
-------------
- Publication format is 1.52.
- Picture Studio format remains 1.4.
- NuGet and npm dependency versions/sets are unchanged.
- Full simultaneous multitrack preview/mixing is deferred; all imported tracks remain canonical and serialized.
