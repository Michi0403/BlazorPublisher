PublisherStudio v1.0.88 source changes
=======================================

Release purpose
---------------
Interaction hardening and publish-candidate recovery after the reported Panel Studio drag race,
Mainframe HTML/Canvas/3D arrangement gap, recurring overlay stacking conflicts, and missing shared
frontend logging/notification boundary.

New domain and service contracts
--------------------------------
- src/PublisherStudio.Web/Domain/PublicationLayoutModels.cs
  Public geometry and layer-order request/result contracts.
- src/PublisherStudio.Web/Domain/UserNotificationModels.cs
  Public notification severity/message contracts.
- src/PublisherStudio.Web/Services/Publication/PublicationElementLayoutService.cs
  Interface-first shared constraints, nudge and deterministic z-order service.
- src/PublisherStudio.Web/Services/UserExperience/IUserNotificationService.cs
- src/PublisherStudio.Web/Services/UserExperience/UserNotificationService.cs
  Scoped frontend notification stream with structured logging.
- src/PublisherStudio.Web/Controllers/PublicationLayoutController.cs
  API adapter for bounds constraints and layer reorder operations.
- src/PublisherStudio.Web/Components/Shared/UserNotificationHost.razor
  Accessible Blazor notification surface.

Mainframe and Panel / Div Studio
--------------------------------
- HtmlEmbedView now uses a designer-only arrangement shield. Embedded HTML, Canvas and generated
  3D content remains interactive in preview/export but participates in the normal object layer while
  arranging in Mainframe or Panel Studio.
- PanelStudio DropDraggedElement captures the complete drag transaction before awaited JS interop,
  validates it after the await, clones the captured prototype, and cleans state in finally.
- Expected circuit disconnect/cancellation paths are debug-logged instead of crashing the circuit.
- Existing Panel Studio objects use pointer capture for mouse, pen and touch movement/resizing rather
  than the racy HTML dragend path.
- Selection, duplicate/delete, nudge, resize and all four z-order operations target the selected ID.
- Ribbon and context menu expose bring-to-front, bring-forward, send-backward and send-to-back.
- Mainframe and Panel Studio expose keyboard and standard Gamepad API command mappings suitable for
  browser-visible Steam Deck/controller input.

Stacking and input policy
-------------------------
- Added a bounded application stacking scale for modal, dialog, notification and export surfaces.
- Replaced application-owned extreme z-index values in CSS and generated standalone HTML controls.
- The release contract rejects application-owned numeric z-index values above 5000; vendor assets are
  intentionally not rewritten.
- Panel hit/drop layers, HTML/map shields and media drop overlays use isolated local stacking contexts.
- Added coarse-pointer resize targets, focus-visible states and touch-action ownership.

Logging and user feedback
-------------------------
- New/touched layout, notification, browser automation and screenshot services use ILogger<T>.
- Mainframe and Panel Studio browser callback failures are logged and sent to the shared notifier.
- Recoverable import/configuration/drop failures notify the user without destroying the Blazor circuit.
- Added the mandatory interaction/stacking/input/frontend-failure release gate to AGENTS.md.

Composition and versioning
--------------------------
- Registered layout as singleton and notification stream as scoped in the composition root.
- Added notification host to the Editor shell and shared imports.
- Updated application, installer, asset package and runtime manifest version to 1.0.88.
- Publication format remains 1.55.

Tests and documentation
-----------------------
- Added tests/interactionAndStackingReleaseGate.test.mjs.
- Updated existing version and panel-composer contracts for v1.0.88 pointer ownership.
- Added docs/architecture/interaction-stacking-and-notification-v1.0.88.md.
- Updated AGENTS.md, README.md, RELEASE.md, ARCHITECTURE.md, system overview and task ledger.
- Added CHANGELOG-v1.0.88.md, this source-change report and TEST-RESULTS-v1.0.88.txt.

Compatibility notes
-------------------
- No publication schema migration is required.
- Palette insertion still supports HTML drag/drop; existing-object arrangement is intentionally based
  on Pointer Events.
- Designer-only shields are not emitted into interactive or render export output.
- Physical Steam Deck/touch acceptance and licensed DevExpress compilation remain developer-machine
  release checks because this environment has no .NET SDK or licensed package feed.
