Upgrade note
------------
When applying these source changes over an existing v1.0.63 working copy, run `dotnet clean` or delete the PublisherStudio.Web bin/obj folders before rebuilding. Visual Studio design-time build state can otherwise temporarily retain the removed Service-local type and continue showing a source/assembly identity error until the cache is rebuilt.
