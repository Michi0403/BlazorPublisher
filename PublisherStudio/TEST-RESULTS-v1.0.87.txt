Reported compiler blocker
-------------------------
Finding: CS9007 in BrowserRuntimeTemplateService.CreateBlobRuntime. The C#
interpolated raw string used two '$' delimiters while the embedded JavaScript
naturally contained adjacent closing braces and JavaScript template-literal
expressions.

Repair: the JavaScript body is now a non-interpolated C# raw string. A unique
__PUBLISHERSTUDIO_BLOB_RUNTIME_PAYLOAD__ marker is replaced once with the
serialized payload using StringComparison.Ordinal. The public service interface,
DI use and generated browser behavior remain compatible.
