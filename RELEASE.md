# PublisherStudio v1.0.73 release

The complete source release is in `PublisherStudio/`.

See `PublisherStudio/CHANGELOG-v1.0.73.md`, `PublisherStudio/SOURCE-CHANGES-v1.0.73.txt`, `PublisherStudio/TEST-RESULTS-v1.0.73.txt`, `PublisherStudio/RELEASE.md`, `PublisherStudio/docs/architecture/video-project-import-doctrine.md`, and `PublisherStudio/VALIDATION.md`.

v1.0.73 adds a canonical open video-project model and safe import/relink workflow for `.otio`, `.otioz`, `.mlt`, `.kdenlive`, `.xges`, `.osp`, and `.edl` projects. It preserves imported editorial structure while projecting one selected video track into the existing Video Studio clip/layer/filter editor.

Application and installer version is `1.0.73`. Publication format is `1.52`; Picture Studio format remains `1.4`; dependency versions are unchanged.
