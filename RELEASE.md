# PublisherStudio v1.0.71 release

The complete source release is in `PublisherStudio/`.

See `PublisherStudio/CHANGELOG-v1.0.71.md`, `PublisherStudio/SOURCE-CHANGES-v1.0.71.txt`, `PublisherStudio/TEST-RESULTS-v1.0.71.txt`, `PublisherStudio/RELEASE.md`, and `PublisherStudio/VALIDATION.md`.

v1.0.71 restores a full-size Video Studio preview, docks the playback/timestamp control to the bottom of the video canvas, makes temporal selection independent of letterboxed source geometry, exposes working pointer modes and fit commands in the ribbon/context menu, synchronizes the selected clip with the project playhead, and repairs inactive frame-overlay Z-order leakage.

Application and installer version is `1.0.71`. Publication format remains `1.49`; Picture Studio format remains `1.4`; dependency versions are unchanged.
