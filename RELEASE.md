# PublisherStudio 3.6.4

PublisherStudio 3.6.4 is a narrow PowerShell parser repair for the documentation browser retry diagnostics introduced in 3.6.3. It preserves the adaptive low-memory and bounded chunk-recovery behavior unchanged while using parser-safe variable delimiting.

The release also adds a source audit that rejects invalid non-scope `$name:` PowerShell references across maintained `.ps1` files before packaging.

See `CHANGELOG-v3.6.4-POWERSHELL-INTERPOLATION-PARSER-REPAIR.md` and `VALIDATION-v3.6.4-source.md`.
