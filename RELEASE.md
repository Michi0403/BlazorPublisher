# PublisherStudio 2.6.5 Media Studio drag/effect/localization release

PublisherStudio 2.6.5 repairs selected Picture Studio object export by making the Picture Studio compositor authoritative, extends the Mainframe drag-transfer contract into Picture Studio and Video Studio, reorganizes Video Studio into a categorized Ribbon/effect-stack workflow, repairs non-finite media seeks and live video effect refresh, improves the shared interactive 3D extrusion runtime, and completes the current German Mainframe/media-studio localization surface with culture-safe CSS icons.

Publication format remains 1.58 and Picture Studio format remains 1.5. No database migration is required. LocalGPT and the word-processing/RichEdit pipeline are unchanged.
