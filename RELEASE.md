# PublisherStudio 3.7.6

PublisherStudio 3.7.6 is a focused build-guard repair release for the 3.7.5 1-Wire format-capability and controller-mode feature set.

The file-format HTTP controller now owns the same structured logging and catch boundary required of other operational controllers. XML documentation has been completed for the new capability models/service, organic capability wiring, and controller-mode Razor members so the maintained documentation gate passes without exemptions.

The established keyboard, pointer, context-menu, Mainframe/Studio and controller systems remain intact.

See `CHANGELOG-v3.7.6-BUILD-GUARD-XML-DIAGNOSTICS-REPAIR.md` and `VALIDATION-v3.7.6-source.md`.
