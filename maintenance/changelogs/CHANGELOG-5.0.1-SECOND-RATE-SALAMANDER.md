# PublisherStudio 5.0.1 — Second-rate Salamander

## Since 4.9.8

- **Editable publications.** PublisherStudio advertises publication creation and refinement through 1-Wire. A linked LocalGPT Council can prepare an editable native document and revise it through the same capability.
- **Media workflows.** Image, video, and audio requests go to the matching LocalGPT Council team. PublisherStudio saves model preferences and shows whether a request completed or failed.
- **Media editing.** The converter accepts dropped files and refreshes format availability after FFmpeg setup. Approved 1-Wire requests can trim an audio or video time range and return the resulting file.
- **Approvals.** A larger panel presents 1-Wire pairing details. Publisher actions can be approved until their scope changes, and saved approvals can be revoked.
- **Build and installer.** Both report version 5.0.1. The release uses DevExpress 26.1.6, restores pinned .NET tools before compiling, and offers an explicit SDK workload refresh.

Cross-platform verification of generated picture and video insertion, canvas playback, and Chat delivery is still in progress.
