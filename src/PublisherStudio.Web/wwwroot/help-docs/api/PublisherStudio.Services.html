Keeps embedded publication media on the server and exposes it through a small ranged HTTP URL. This prevents multi-megabyte data URLs from being copied into every Blazor render batch. The original data URL remains in the document model so saved projects stay self-contained.

PublicationWebDataService

Resolves the transport described by PublicationWebBinding into an embedded source snapshot. The binding is deliberately independent from charts so later web-content and streaming adapters can reuse the same request contract.

PublicationWebhookStore

In-memory webhook mailbox for the loopback PublisherStudio process. Tokens are registered from the currently open publications so unknown binding ids cannot inject data into the application.
